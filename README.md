## Project Overview

This repository contains the practical implementation, configuration, documentation, and learning materials for Oracle Fusion Financials – General Ledger (GL).

The project focuses on understanding and implementing the key General Ledger configuration and accounting processes in Oracle Fusion Cloud Financials.

## Project Objectives

- Understand the Oracle Fusion General Ledger architecture and setup.
- Configure the main General Ledger components.
- Build and configure the Chart of Accounts.
- Configure Ledgers, Legal Entities, and Business Units.
- Create and manage accounting journals.
- Perform journal posting and accounting processes.
- Configure automated posting and reversal.
- Generate and analyze General Ledger reports.
- Document the implementation process and practical exercises.
